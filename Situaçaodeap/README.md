# 📰 NewsToday

## 📌 Descrição do Projeto

O NewsToday é um portal de notícias moderno e responsivo desenvolvido utilizando HTML5 e CSS3. O projeto apresenta notícias organizadas em categorias, oferecendo uma interface elegante, intuitiva e adaptável a diferentes dispositivos.

---

# 🚀 Melhorias Realizadas

Durante o desenvolvimento do projeto, foram implementadas diversas melhorias:

* Criação de um menu fixo para facilitar a navegação.
* Adição de efeito de transparência e desfoque no menu usando `backdrop-filter`.
* Inclusão de animações nos botões e cartões utilizando `hover`.
* Organização das notícias em formato de cards.
* Implementação de imagens ilustrativas para melhorar a experiência visual.
* Criação de categorias para identificar rapidamente o tema das notícias.
* Desenvolvimento de layout responsivo para celulares e tablets.
* Utilização de Grid Layout para organizar os cards automaticamente.

---

# 🏗️ Elementos Semânticos Utilizados

Foram utilizados elementos semânticos do HTML5 para melhorar a organização e acessibilidade do site:

| Elemento               | Função                           |
| ---------------------- | -------------------------------- |
| `<header>`             | Cabeçalho principal da página    |
| `<nav>`                | Menu de navegação                |
| `<main>`               | Conteúdo principal               |
| `<section>`            | Agrupamento de conteúdos         |
| `<article>`            | Representa cada notícia          |
| `<footer>`             | Rodapé do site                   |
| `<h1>`, `<h2>`, `<h3>` | Títulos e hierarquia de conteúdo |
| `<p>`                  | Parágrafos de texto              |

O uso desses elementos melhora a estrutura do site e auxilia mecanismos de busca e tecnologias assistivas.

# 📱 Media Queries Implementadas

Foram utilizadas Media Queries para tornar o site responsivo:

## Até 768px

```css
@media (max-width: 768px)
```

Alterações realizadas:

* Menu organizado em coluna.
* Links centralizados.
* Redução do tamanho dos títulos.
* Ajuste das imagens.
* Grid de notícias adaptado para duas colunas.

## Até 480px

```css
@media (max-width: 480px)
```

Alterações realizadas:

* Menu deixa de ser fixo.
* Cards passam para apenas uma coluna.
* Textos ficam menores.
* Botões ocupam maior espaço.
* Redes sociais são exibidas em coluna.

# 🎨 Decisões de UX e UI Adotadas

## UX (User Experience)

* Navegação simples e intuitiva.
* Menu sempre acessível ao usuário.
* Organização clara das categorias de notícias.
* Rolagem suave entre seções utilizando `scroll-behavior: smooth`.
* Layout responsivo para diferentes dispositivos.

## UI (User Interface)

* Paleta de cores suaves em tons de rosa.
* Botões arredondados para aparência moderna.
* Efeitos visuais ao passar o mouse.
* Uso da fonte Poppins para melhorar a leitura.
* Cartões com sombras para destacar informações importantes.
* Imagens grandes e de alta qualidade para maior atratividade visual.
